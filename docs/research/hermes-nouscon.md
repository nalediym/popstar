## 5. Interop
- **Would our skills port?** Yes, nearly as-is. Claude Code skills are SKILL.md + `name`/`description` frontmatter, which is the agentskills.io format Anthropic originated and Hermes loads [S32][S19]. Our three skills have exactly that. Paths: `skills.external_dirs: ["<repo>/.claude/skills"]`, or copy to `<repo>/.hermes/skills/` (loads after `trust`), or `~/.hermes/skills/popstar/`. Add `platforms`, `required_commands: [bun, ffmpeg, uv]` and `metadata.hermes.requires_tools` for a clean install.
- **What breaks**: (1) tool names: our skills say `mcp__comfy-cloud__submit_workflow`; in Hermes the same server registers as `mcp_comfy_cloud_submit_workflow` [S31]. Write tool references generically or keep a 10-line name map. (2) Claude-only affordances: Agent tool → `delegate_task`; `.claude/workflows` + hooks → `hermes cron`/kanban; `/popstar` → `/popstar-pipeline` (skills are slash commands) or a skill bundle [S19][S22][S21]. (3) The browser-pane recorder is a plain web page; the Blender previs maps to Hermes's official Blender Lab MCP plugin [S48]. (4) Comfy Cloud auth goes in `mcp_servers.comfy-cloud.headers` (bearer or `X-API-Key`) [S31].
- **Could Hermes run the whole pipeline?** On paper yes: skills + MCP + terminal + ffmpeg, and Hermes ships its own `comfyui` skill that targets Comfy Cloud over REST, bypassing the MCP [S43]. **UNVERIFIED**: not executed.
